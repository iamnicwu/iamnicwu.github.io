## 配置要点（改 hugo.toml 前先读）

- `[outputs] home = ["HTML","RSS","JSON"]` —— PaperMod 的 Fuse.js 搜索依赖这个 `index.json`
- `params.fuseOpts.threshold = 0.4` —— 中文检索不放宽基本搜不到
- `[markup.highlight] noClasses = false` —— 必须显式写死，PaperMod 深浅色代码高亮依赖 class
- `[markup.goldmark.parser] wrapStandAloneImageWithinParagraph = false` —— 否则 `<figure>` 被包进 `<p>`，是无效 HTML
- **不要加 `languageCode`**（Hugo 0.158 起弃用）；也不要加显式 `[languages]` 块（会让 PaperMod 找不到 layout）

## 踩过的坑（都是真 bug，不是风格问题）

1. **`{{< relref >}}` 不能写在 Markdown 链接的 `()` 里** —— 会产出 `href=//tags/`，浏览器按协议相对 URL 解析成 `https://tags/`，必然 404。放进原生 HTML 的 `href="..."` 里则正常。
2. **`render-link.html` 里不能对以 `/` 开头的路径用 `relURL`** —— 会拼成 `//tags/`。只对真正相对的路径才过 `relURL`。
3. **`cover.image` 会被 `absURL`** —— 本地用生产产物预览时，封面图指向线上域名而拿不到。要本地看封面得单独构建：
   `hugo --baseURL http://127.0.0.1:4002/ -d /tmp/preview`
4. **少四个 favicon 文件 → 每页 4 个 404**。PaperMod 的 `head.html` 默认引用 `favicon-16x16.png` / `favicon-32x32.png` / `apple-touch-icon.png` / `safari-pinned-tab.svg`，`static/` 里只有 `favicon.ico`。已从 ico（内部是 352×352 PNG）派生补齐。
5. **`.project-version` 徽章被挤成两行** → `flex: 0 0 auto; white-space: nowrap`。
6. **窄图被放大发虚**：侧栏截图只有 400px 宽，正文栏 720px，顺其放大 1.8 倍在 Retina 上明显糊。加了 `.post-figure.is-narrow`（限宽 440px 居中），这类图要用原生 HTML 写。
7. **选封面优先挑 1440 宽的整屏截图**：列表缩略图会被裁成横幅，`400x1416` 这种超长竖图裁完基本看不出内容；只有方形图标时用 Chrome 渲染合成一张 1200×675 横幅再当封面。

## 校验手段（可复用）

- 全站内部链接校验要**同时覆盖 `/…` 和 `https://iamnicwu.github.io/…` 两种写法**，并 `decodeURIComponent`（中文标签页是 percent-encoded），否则漏检。当前 488 条全绿。
- Chrome + CDP 截图核对：必须加 `--no-proxy-server` 且清掉 `HTTP_PROXY`，**每次用全新 `--user-data-dir`**（复用 profile 会缓存上一轮的 404，看起来像图片全坏）。
- `resources/_gen` 缓存会让样式改动不生效；构建异常先 `rm -rf resources/_gen`。
- 本机 Node 命令一律要 `env -u NODE_OPTIONS`。

## 分享到外平台

`node scripts/export-shares.mjs` → `shares/*.md`。除原有的「去 front matter + 图片换绝对 URL」，
**新增 `<figure>` → 「Markdown 图 + 斜体图注」的降级**：外平台对自定义 class/HTML 支持不齐（掘金丢 class、知乎整块不认），不降级图注会一起消失。
