**踩坑（重要）**

1. **PaperMod 的 footer 是 `partialCached`**，cache key 只有 `.Layout .Kind hideFooter ShowCodeCopyButtons`，不含页面。在 `extend_footer.html` 里按 `.Section` 做条件输出会**串页**（项目页拿到文章页的 footer）。正确做法：partial 里无条件输出，脚本内用 `document.documentElement.classList.contains("is-article")` 判断；`is-article` 由 `extend_head.html`（普通 partial，条件可用）在 `<html>` 上打。
2. **「项目」页也用 `article.post-single`**，所以 TOC 侧栏规则必须限定 `html.is-article`，否则项目页的目录会被 fixed 到右上角。
3. `hugo --minify` 会删 HTML 注释，用注释做调试输出看不到；用 `warnf` 或可见属性。
4. `--minify` 增量构建可能保留旧页面产物，验证 `public/` 前先 `rm -rf public`。
5. headless 截图会命中浏览器缓存，`Page.navigate` 前要 `Network.setCacheDisabled` 或换 profile，否则看到的是旧样式。
