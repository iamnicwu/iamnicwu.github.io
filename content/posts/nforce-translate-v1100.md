设置页原来有个「保存设置」按钮，改完不点就等于白改。现在这个按钮**去掉了**：改哪个存哪个。

## 怎么存的

- **下拉框、开关、主题**：点完立刻写入，不等
- **API Key / 接口地址 / 模型名**：停手 0.6 秒后写入（不然每敲一个字都要写一次本地存储）
- **失焦**：立刻补写一次，不用等那 0.6 秒
- **切走页面 / 关掉**：还有没落盘的改动会补一次，不会因为防抖把最后几个字吞了
- `Cmd/Ctrl + S` 仍然有效，等于让它立刻落盘

底部状态栏平时写着「改动会自动保存」，存完变成「已自动保存」，1.8 秒后自己淡回去。

## 两个容易踩的坑，顺手处理了

**一、别把状态搞脏。** 自动保存默认是不做硬校验的。以前选了「AI 模型」却没填 Key，点保存会直接被拦住、什么都不写；放到自动保存上就变成「改个划词开关也存不进去」。现在的做法是：照存，但状态栏用红字提醒「已保存，但「AI 模型」还没填 API Key，翻译会失败」——要不要填由你决定，别让一个字段卡住所有设置。

**二、别让并发的写入互相盖掉。** 快速连改几个开关时，几次写入可能同时在路上，后返回的旧值会把刚改的新值盖回去。所以写入做了串行化：上一次没回来时只记一句「再来一次」，回来后再补一次最新的完整表单。

## 顺带

「沿用翻译的 AI 配置」按钮点完也是直接生效，不再提示「记得保存」。
