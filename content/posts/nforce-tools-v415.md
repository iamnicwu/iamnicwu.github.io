上一篇写 nForce Tools 的时候还是 v4.4，首页是分组卡片，功能二十来个。之后又改了一轮，现在到 v4.15。

多出来的东西按我自己用得多的顺序排：全局搜索、日志查看器、批量查询、Order 历史。首页也整个重做了一版。

## 敲两下就能跳到功能

首页现在有 29 个入口，名字里一堆缩写：T-4、VVIP、PCD、CVP7。记不住很正常，我自己也记不全。

按 `Ctrl/Cmd + K` 会浮出搜索框，在任意网页上按 `Alt+Shift+S` 也一样。打 `t4` 能出 T-4 Outstanding，打 `ltsdaily` 能出 LTS 概览，打中文也可以。选中回车直接落在那个功能上，不经过首页。

没连 Salesforce 的时候点结果，会先自己连一次，用的是浏览器里现成的登录态。连上就进去，不用先去设置页走一趟。

面板刚打开只列常用功能。铺满一屏的搜索结果，人还是得用眼睛扫一遍，不如先给几个顺手的。

![全局搜索](/post-images/nforce-tools-v415/02-search.png "输入 log，命中的是 View Log。回车直接进功能，不新开标签也不经过首页")

## 首页变成方格了

以前是分组卡片，26 个图标带描述，400px 的侧边栏要滚三屏才看完。现在是一片方格：单项的分组直接摆成图标，成组的收进文件夹，文件夹里是 2×2 的缩略图，超过四项时右下角标一个 +N。

可以自己拖。拖到文件夹上是加进去，拖到另一个图标上是新建文件夹，从面板里拖出去就是移出来。整理完刷新还在。

## 工具类的功能改成整页开

Bulk 操作、Execute Anonymous、View Log、批量 SOQL 查询、Metadata 这些，挤在 400px 里很难用。现在点开会在新标签页里打开，页面锁在一屏，滚动的只有卡片里面的内容，标题和返回键钉在顶上。

LTS 日报、报表这些还是留在侧边栏。这类页面本来就是从上往下读的，侧边栏反而更专心。

## 新页面：Order 历史

输一个 Order 的 Name、Id 或 Order Number，列出这条记录改过什么：时间、字段、旧值、新值、操作人，能导 Excel。

下面还有一张「Order 字段」表，把这条记录的字段全列出来，一条记录一行，字段多的时候横向滚。

搜索框里输入一个像单号的值，结果第一条会变成「查询 Order 历史」，回车就查。

查不到的情况分三种，提示也不一样：没有这个 Order；有这个 Order 但字段历史是空的（org 没给 Order 开追踪，Salesforce 默认不开）；这个 org 连 OrderHistory 对象都没有。三种情况的下一步完全不同，合成一句「查询失败」等于没说。

页面底部有一份查询日志，写着这次把值识别成了什么、发了哪条查询、返回几条。出错时自动展开。

## 新页面：View Log

给一个 Log ID，或者直接粘贴日志正文，就能看一份 Apex 日志里的东西：

- 概览：耗时、行数、SOQL 和 DML 各跑了几次
- 最慢的几步，按每一步自己的耗时排
- 调用树，可以一层层展开
- SOQL、DML、异常，各占一页
- 原始日志，完整正文，能复制也能存成 .log

顶部六个标签页，条数直接写在标签上。工具条钉在上面，页面本身不滚。

日志大的时候会先报体积和行数再开始读，几十 MB 那种也不会点了没反应。原始日志一页 500 行，可以翻页。关键字筛选只留命中的行，支持区分大小写和正则，留下来的行号还是原文的行号。

原始日志上了色：事件名、级别、触发器阶段、时间戳各一种颜色。找 `USER_DEBUG` 的时候不用从头一行行扫。

粘贴正文这条路不用连 Salesforce，没登录也能开。

## Execute Anonymous 跑完能直接看日志

以前跑完只告诉你编译成功还是执行成功，日志得自己去 Setup 里翻。而 org 默认不给任何用户开日志，翻过去大概率是空的。

现在执行完会把这一次的日志取回来，带上体积、耗时、状态和完整正文，能复制也能下载。日志没取到不影响执行结果，只是下面多一行说明是哪一环没成。

## 写 SOQL 和 Apex 有提示了

SOQL 查询框、批量查询的模板框、Execute Anonymous、View Log 的原始日志，四处都换成带行号和语法着色的编辑器。`Ctrl+F` 能搜，括号会配对高亮，长语句自动折行。

补全给的是对象名、字段名、聚合函数、日期写法、关键字。光标停在 `SELECT` 里，后面 `FROM Account` 已经写好了，提示的就是 Account 的字段。写成 `FROM Account a` 再打 `a.`，给的也是 Account 的字段。

`Ctrl+Space` 可以手动叫出来，上下键选，回车或 Tab 采用。

## 批量 SOQL 查询

新页面。拖一份 CSV 或 Excel 进去，挑一列当查询条件，Order Number、Name、Id 会按列名和值的形状自己认出来。再写一份带占位符的 SOQL 模板，它按批并发去查，进度和「停止」都在界面上。

跑完会算出来哪些值在 Salesforce 里查不到，单独列一份清单。导出的 Excel 有两个工作表，一个是查到的，一个是没查到的。

CSV 用自己的解析，`00012345` 这种前导零不会变成 `12345`。

以前要拿两百个单号查一遍，得把单号拼进一条很长的 SOQL 再贴过去，还得担心 URL 太长。现在拖个文件就行。

## 查询历史能命名，也能带走

SOQL 和 Execute Anonymous 的历史，从一个下拉框变成了面板。

每条都能起名字，点一下就地改，回车存下来。历史攒多以后这个很必要，一段 SOQL 缩略到一行，几条看着都差不多。

顶部有筛选框，按名字或语句内容过滤。勾选以后可以批量删除、导出 JSON；不勾选时，导出和同步都按当前筛选结果走。

导入认三种文件：自己导出的 JSON、手写的 JSON 数组、`.sql` / `.apex` 纯文本。导回自己刚导出的那份不会翻倍。

上限从 20 条提到 100 条。

还能同步到 ima 知识库。填 Client ID 和 API Key，选一个知识库，历史会按一条一个标题加代码块写进去。换电脑的时候比传文件省事。

## 一些小的

**请求超时**。默认 120 秒，设置里能改。以前一个请求挂住，界面就永远停在 loading；侧边栏没有地址栏，也刷新不了，只能关掉重开。

**定时任务补报**。侧边栏收起来的时候触发的提醒，以前就这么没了，界面上也没有记录。现在下次打开会补一条汇总，说错过了几个。

**不会跑两遍**。取数、导出、执行 Apex 这些动作，双击不会变成两次查询、两个文件，也不会让同一段 Apex 执行两遍。按钮在执行期间是禁用的。

**关系字段能正常显示**。`SELECT Order__r.OrderNumber` 以前出来是一列 `Order__r`，值是 `[object Object]`。现在列名是 `Order__r.OrderNumber`，值也是真值，导出跟着对。

**改名**。「SOQL 导出」现在叫「SOQL 查询」，因为它不只导出了。

**删了两个**。贴边浮窗和侧边栏自动隐藏去掉了。全局搜索能在网页上直接唤起以后，鼠标移到屏幕边缘滑出面板这件事就没那么必要了。

**首页底部**多了版本号和 GitHub 入口。

## 安装

还是没上架商店：

1. 从 [GitHub](https://github.com/iamnicwu/nForce-tools) 拉代码，或者直接下 `dist/`
2. 打开 `chrome://extensions/`，右上角开发者模式
3. 加载已解压的扩展程序，选 `dist/` 或仓库根目录

点工具栏图标可以整页打开，点侧边栏图标就常驻在右边。

全局搜索的快捷键如果和别的扩展撞了，去 `chrome://extensions/shortcuts` 改。Chrome 对冲突的快捷键不报错，只留空，所以按了没反应的时候先去那里看一眼。

## 最后

这一轮改的东西比看上去多，大部分是为了让功能多起来之后还找得到、用得顺。功能本身没什么新鲜的，Salesforce 该有的 Setup 里都有，只是散在七八个地方，每次找一遍都挺费劲。
