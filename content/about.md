你好，我是 Nick。

这个博客断断续续开了很多年，中间换过几次引擎，从 Gridea 到 Hugo，落到现在这套 Hugo + PaperMod。留下的都是做完东西之后的复盘。

## 这里会有什么

- **做过的东西。** 主要是浏览器扩展和给日常业务用的小工具，写完会把设计取舍和踩过的坑一起记下来。目前最集中的是 [nForce 系列的四款 Chrome 扩展](/projects/)。
- **技术笔记。** Chrome Manifest V3 那一堆约束、Salesforce 的 API 边界，以及我自己判断失误之后改回来的地方。
- 偶尔也有些跟技术无关的碎念，不多。

## 我在意的事

写 JavaScript 为主，打交道最多的是浏览器扩展、前端工程，和一些把重复劳动变自动化的脚本。相信工具应该长在顺手的地方：需要的时候它就在那儿，不需要的时候最好别挡路。上面那几款扩展基本都是这条原则的产物。

放到写代码上也一样：不要让用户面对一次「什么都没发生」。失败要说清楚是哪一环断了，这是我做工具时反复回到的一条线。
